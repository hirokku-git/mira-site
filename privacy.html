MIRA（Moodle Integrated Reminder Assistant）

最終更新日：2026年10月3日

1. このアプリについて

MIRA は、作者本人だけが使う個人用のリマインダーアプリです。 一般の利用者には提供しておらず、作者以外の Google アカウントのデータを扱うことはありません。

2. アクセスする Google のデータ

MIRA は、Google Calendar API の https://www.googleapis.com/auth/calendar.events の権限を使い、作者本人の Google カレンダーにある専用カレンダー「MIRA 課題」の予定だけを作成・更新・削除します。 その他のカレンダーの予定、メール、連絡先など、それ以外の Google のデータにはアクセスしません。

3. データの使い道

Google から受け取ったデータは、Moodle の課題の締め切りとカレンダーの予定を比べて、 予定を最新の状態に保つためだけに使います。広告、分析、販売、第三者への提供には一切使いません。

4. データの保存

MIRA は独自のサーバーやデータベースを持たず、カレンダーの予定のデータを保存しません。 Google にアクセスするための認証情報は、作者本人の環境（パソコンと GitHub の非公開の Secrets）にだけ保存します。

5. 第三者への提供

Google から受け取ったデータを第三者に渡すことはありません。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

MIRA が Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

7. アクセス権の取り消し

Google アカウントのサードパーティ アクセスの設定 から、いつでも MIRA のアクセス権を取り消せます。

8. お問い合わせ

このポリシーについてのお問い合わせは、GitHub（hirokku-git） までご連絡ください。
